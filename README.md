# ALS Gene Browser

An interactive Shiny app for exploring transcriptomic data from the NYGC ALS Consortium: differential gene expression across tissues, *C9orf72* status, and clinical variables in ALS and control post-mortem samples.

## Access

- **Shiny app:** https://alsbrowser.nygenome.org/
- **Preprint:** https://www.medrxiv.org/content/10.64898/2026.04.29.26350889v1
- **Data (Zenodo):** https://zenodo.org/communities/nygc_als/records
